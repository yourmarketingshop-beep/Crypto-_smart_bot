# دليل تجهيز وتثبيت Crypto Smart Bot – الإصدار 24

## حالة الحزمة
هذه حزمة المشروع النهائية عند المرحلة 24. لا تضيف هذه الخطوات ميزات جديدة؛ هدفها بناء ملف Android APK فقط. الحزمة الحالية تحتوي على المصدر وملفات إعداد البناء، ولا تحتوي على APK جاهز.

## قبل تثبيت التطبيق
التطبيق Flutter يحتاج إلى خادم FastAPI ليقرأ بيانات الحساب والمؤشرات. يجب تشغيل الخادم على جهاز أو استضافة يمكن للهاتف الوصول إليها. لا تستخدم `http://10.0.2.2:8000` على هاتف Android حقيقي؛ هذا العنوان مخصص لمحاكي Android.

- أثناء الاختبار على شبكة منزلية: استخدم عنوان IP للكمبيوتر الذي يشغل الخادم، مثل `http://192.168.1.20:8000`، مع اتصال الهاتف والكمبيوتر بالشبكة نفسها.
- للاستخدام من خارج الشبكة: انشر FastAPI على استضافة موثوقة مع HTTPS.
- لا تضع مفاتيح تداول Binance في التطبيق أو الخادم. المشروع مخصص للتداول الافتراضي فقط.

## بناء APK باستخدام GitHub Actions
1. نزّل ملف ZIP وفك ضغطه على كمبيوتر.
2. أنشئ مستودعاً جديداً على GitHub.
3. ارفع محتويات مجلد `crypto_smart_bot_rebuild` إلى جذر المستودع، مع الحفاظ على مجلد `.github` وملف `.github/workflows/android-apk.yml`.
4. افتح المستودع في GitHub ثم **Actions**.
5. اختر **Crypto Smart Bot checks and Android APK** ثم **Run workflow**.
6. أدخل في `bot_api_url` عنوان FastAPI الذي يستطيع هاتفك الوصول إليه. لا تترك العنوان الافتراضي `http://10.0.2.2:8000` إذا كنت ستثبت التطبيق على هاتف حقيقي.
7. ابدأ التشغيل وانتظر حتى تنجح مهمتا `backend-tests` و`android-apk`.
8. افتح تشغيل البناء الناجح، ثم نزّل ملف **crypto-smart-bot-android-apk** من قسم **Artifacts**.
9. فك ضغط ملف Artifact على الهاتف، وافتح ملف APK وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر؛ لا تسمح إلا إذا كنت تثق بالمصدر والملف.

## تشغيل الخادم
من مجلد `backend` على جهاز متصل بالشبكة أو على استضافة:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

تحقق من عمله بفتح `/health` على عنوان الخادم. عند نشره عبر الإنترنت استخدم HTTPS وإعدادات حماية مناسبة.

## تنبيهات مهمة
- لم يتم بناء APK أو تثبيته واختباره على هاتف ضمن بيئة إعداد هذه الحزمة؛ يجب تنفيذ خطوات GitHub أعلاه لإنتاجه.
- لا يعني نجاح بناء APK أن خادم FastAPI منشور أو متصل؛ يجب إعداد الخادم بصورة مستقلة.
- بيانات Binance المستخدمة عامة للقراءة والتحليل فقط. لا توجد أوامر تداول حقيقية؛ حافظ على وضع PAPER ONLY.
- نتائج الاختبار التاريخي والمحاكاة لا تضمن أرباحاً مستقبلية.
